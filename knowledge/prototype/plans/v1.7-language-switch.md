# v1.7 — EN / 中文 on the caregiver and kaki screens

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers-executing-plans, one task at a time, TDD per task. Steps use checkbox syntax.

**Goal:** a caregiver or kaki can flip the whole app to Simplified Chinese with one tap, and it stays that way — on this phone, on the next phone, and in the messages we send them. The coordinator console stays English.

**Architecture:** one dictionary file (`frontend/js/i18n.js`) with `en` and `zh` maps keyed by short stable ids; `UI.t(id, vars)` looks up the current language and falls back to English. Views stop containing literal English. The chosen language lives in `localStorage.kakis_lang` (so the sign-in screen can be Chinese before anyone is signed in) and in `users.lang` (so notifications and a second device follow the person). Backend errors that a senior might read carry a stable `error` code next to the English `detail`; the frontend maps the code to Chinese. Notifications choose a template by the recipient's `users.lang`. The help bot answers Chinese questions from a Chinese keyword table.

**Tech stack:** FastAPI + DuckDB, no-framework JS, Playwright 1.63, `backend/tests/smoke.py`. No build step, no library.

**Spec:** `app/SPEC.md` §2 (module boundaries), §9.5 (hard rules). This plan adds §7 (i18n rules), §9.0, §9.3, §10 v1.7.

## Global constraints

- Coordinator console: `views/admin.js` is not touched; no toggle when `App.user.role === "admin"`; admin screens render English even when the phone is Chinese.
- Data stays English: service, trigger, language and status values are stored and sent to the API exactly as before. Only display changes.
- User-typed text is never translated: names, notes, reasons, reports, care plans, addresses.
- Glossary: Kaki stays "Kaki"; start code 开始码; kaki code Kaki 验证码; caregiver 照顾者; visit 探访; coordinator 协调员; care plan 照护计划. Simplified Chinese as spoken in Singapore, short sentences, no idioms.
- Frontend fetch only in `api.js`. Routers never import each other. Migrations are `ADD COLUMN IF NOT EXISTS` before `CHECKPOINT`.
- All 24 existing Playwright specs and 368 smoke assertions stay green. Asset URLs bump to `?v=1.7`.
